สแกน QR Code จากพนักงานเพื่อสะสมแต้มและรับรางวัล

เข้าสู่ระบบ Admin

วิธีใช้งาน

1. พนักงานสร้าง QR Code ประจำวันจากหน้า Admin

2. ลูกค้าสแกน QR Code แล้วกรอกเบอร์โทรศัพท์

3. ได้รับ 10 คะแนนต่อวัน (1 ครั้ง/วัน)

4. สะสมคะแนนถึงเกณฑ์เพื่อรับรางวัล
